# Maison Céleste

Luxury hair salon website — **Next.js 15**, React, TypeScript, Tailwind CSS, Framer Motion.

**Maison Céleste** — *Luxury Hair. Timeless Style.*

## Run locally

```bash
cd aurelia-skin-studio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

Update name, contact, and images in `src/lib/brand.ts`.
